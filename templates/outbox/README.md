# outbox/

Non-code work I produce for the client: documents, slides, studies, diagrams.

- One folder per deliverable, date-prefixed (e.g. `2026-10-skills-marketplace/`).
- Code deliverables do NOT live here: they are commits/PRs in `workspace/`.
  If useful, keep a one-line pointer (repo + PR link) in the deliverable's folder.
- The final version goes into the client's tooling (Confluence, SharePoint...).

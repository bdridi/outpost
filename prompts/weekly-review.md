# Weekly review

Working directory: the `notes/` folder. Follow the rules in `AGENTS.md`. Task:

1. Read every daily note of the current ISO week, public and private.
2. Create or complete notes in the right folders:
   - theme with >= 3 mentions -> `topics/`
   - decision -> `decisions/`
   - procedure or command -> `guides/`
   - new person -> a row in `people/people.md`
   - fact imposed by the client -> `context/`
3. Add a `[[wikilink]]` from the source daily note to each promoted note.
4. Work on a branch `review/<year>-W<week>` (e.g. `review/2026-W41`), commit, then stop.
5. Commit message = summary: what was promoted and where, what was not filed.
6. Open questions: append them at the end of Friday's daily note
   (the private one if they concern private content).
